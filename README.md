# gacha

イベントの抽選会で使う、スマホ向けのガチャガチャです。GitHub Pages だけで動き、サーバーや DB は使いません。

- 参加者は配布された QR コードを読み取り、自分のスマホでガチャを回します。
- 管理画面で、タイトル・イベント ID・カプセル（色・ラベル・数）を決めて QR を発行します。回数や期間の制限はありません。
- URL を書き換えても通らないよう、設定にハッシュを付けています。

## 使い方

### 1. 合言葉を設定する（初回のみ）

URL の改ざんチェックには合言葉を使います。リポジトリの **Settings → Secrets and variables → Actions → Variables** タブで、変数 `GACHA_SECRET` にランダムな文字列を登録してください（同名の Secret でも動きます。両方ある場合は Variable が優先されます）。

合言葉はビルド時にページへ埋め込まれ、画面が内部で使います。管理画面で入力することはないので、値を覚えておく必要はありません。未設定の場合は初期値 `change-me` になり、管理画面に警告が出ます。

### 2. GitHub Pages に公開する

**Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。`main` に push すると `.github/workflows/deploy.yml` が動き、次の URL で公開されます。

| 画面       | URL                                                         |
| ---------- | ----------------------------------------------------------- |
| 管理画面   | `https://<user>.github.io/gacha/admin.html`                 |
| ガチャ画面 | `https://<user>.github.io/gacha/#d=…&h=…`（管理画面で発行） |

### 3. QR を発行する

1. 管理画面を開き、イベント名・イベント ID・カプセル（色・ラベル・数）を入力します。数は「出やすさ」で、確率が自動で表示されます。
2. 「URL と QR コードを発行する」を押し、QR を画像で保存して印刷・掲示します。

入力内容はブラウザに下書きとして保存されます。発行済みの URL を貼り付けて、設定を読み込み直すこともできます。

### 4. 当日の運用

- 参加者は QR から開いて「ガチャを回す」を押します。結果画面を受付で見せてもらいます。
- 結果画面には秒単位で動く現在時刻が出るので、スクリーンショットの使い回しと見分けられます。
- スタッフが画面を操作する手順はありません。

### 古い QR を無効にしたいとき

Variable `GACHA_SECRET` を別の値に変えて、Actions の「Deploy to GitHub Pages」を再実行してください。それまでに発行した URL はすべて「無効な QR コード」になります。

## 仕様と割り切り

| 項目             | 仕組み                                                                                       |
| ---------------- | -------------------------------------------------------------------------------------------- |
| URL              | `#d=<設定 JSON の Base64URL>&h=<ハッシュ>`。フラグメントなのでサーバーには送られません       |
| ハッシュ         | `d` の文字列に対する HMAC-SHA-256（鍵は合言葉）の先頭 16 バイト                              |
| 抽選             | 数を重みにした抽選。乱数は `crypto.getRandomValues`                                          |
| 結果の履歴       | 端末の `localStorage` に、イベント ID と日付（日本時間）ごとに記録。画面には最近 10 件を表示 |
| 記録のタイミング | 「回す」を押した時点で保存し、その後に演出を流す                                             |

DB を持たないため、次の点は割り切っています。

- **在庫は保証しません。** 数は確率の重みです。「1等 1 つ」でも複数人に出ることがあります。
- **回数や期間の制限はありません。** 何度でも回せるので、1 人 1 回などのルールは受付で運用してください。結果の履歴が画面に残るので、確認の手がかりになります。
- **管理画面は誰でも開けます。** `admin.html` を開けば誰でも有効な QR を発行できます。防げるのは、発行済みの URL の数字を書き換えるような改ざんです。

## 開発

Node.js 22 以上が必要です。

```bash
npm install
```

```bash
npm run dev
```

開発サーバーでは `http://localhost:5173/admin.html` が管理画面です。

| コマンド            | 内容                               |
| ------------------- | ---------------------------------- |
| `npm run lint`      | Biome で lint とフォーマットを確認 |
| `npm run lint:fix`  | Biome で自動修正                   |
| `npm run typecheck` | TypeScript の型チェック            |
| `npm test`          | Vitest でテスト                    |
| `npm run build`     | 本番用ビルド（`dist/`）            |
| `npm run ci`        | 上記をまとめて実行                 |

### 構成

```
index.html / admin.html   ページの入口
src/config.ts             合言葉（VITE_GACHA_SECRET）
src/lib/                  画面に依存しないロジック（ハッシュ、抽選、履歴の記録、日時）
src/gacha/                ガチャ画面
src/admin/                管理画面
```
